## Requirements

- macOS 14 or newer
- Accessibility permission for global shortcuts and paste commands

## Install

Download the versioned ZIP and matching `.sha256` file. Verify the checksum,
unzip Qipli, move `Qipli.app` to `/Applications`, and launch it. The app is signed
with Developer ID and notarized by Apple.

## Using Qipli

Onboarding explains the local clipboard history and can be skipped or reopened
from Settings. Settings contains Accessibility status, configurable Qipli
shortcuts, and an opt-in Launch at Login control.

## Privacy

Qipli keeps 30 days of text clipboard history on the current Mac. It has no
account, telemetry, cloud sync, or automatic secret filtering. Copied passwords
or API keys can enter local history. The current version does not make runtime
network requests.
