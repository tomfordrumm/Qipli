# Qipli app icon source

`QipliIcon-master.png` is the project-owned source image used to generate the
macOS `AppIcon` asset catalog. The image was generated with the built-in OpenAI
image tool on 2026-08-28, then inspected and resized with macOS `sips`.

Final prompt:

> Create a production macOS app icon for Qipli, a private clipboard history and
> sequential paste utility. Use a dark navy glass rounded-square tile, subtle
> layered paper or clipboard sheets, and one luminous cyan-to-violet ribbon that
> forms an abstract Q and suggests copy-to-paste motion. Keep a crisp silhouette
> that remains recognizable at 16px. Use no text, UI screenshot, device mockup,
> watermark, or unrelated symbols. Keep the canvas transparent outside the icon.
